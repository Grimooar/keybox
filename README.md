# Ключница

Менеджер паролей для себя и команды, устроенный по образцу Bitwarden. Пароли шифруются и расшифровываются только на устройстве. Маленький сервер на Cloudflare хранит зашифрованные данные и следит, кто что может делать.

- Работает на компьютере и телефоне, ставится как приложение (PWA).
- Коллеге достаточно ссылки-приглашения: он открывает её, придумывает мастер-пароль, админ принимает заявку. Никаких аккаунтов.
- У каждого есть личный сейф. Есть коллекции для всей команды и коллекции для выбранных людей.
- Роли: владелец, админы, участники. Удалённый человек теряет доступ сразу на всех устройствах.
- Генератор паролей, коды 2FA (TOTP), история паролей, импорт из Bitwarden, Chrome, Edge, Яндекс Браузера и Firefox.
- Без сети можно открыть сейф и смотреть пароли из последней синхронизации.

Приложение: https://grimooar.github.io/keybox/ · Сервер: `server/` (Cloudflare Workers + D1, бесплатный тариф).

## Как это защищено

| Что | Как |
|---|---|
| Мастер-пароль | Нигде не хранится. Из него на устройстве получается ключ (Argon2id, 64 МБ), а из ключа два независимых подключа: один шифрует ваши ключи, второй проверяет пароль на сервере |
| Вход | Сервер отдаёт ваши зашифрованные ключи только после проверки пароля. После 8 неудачных попыток вход блокируется на 15 минут. Так никто не может скачать файл и перебирать пароль у себя |
| Записи | AES-256-GCM, у каждой коллекции свой ключ. Ключ запечатан отдельно для каждого участника с доступом (X25519) |
| Состав команды и права | Файл команды подписывает владелец или админ (Ed25519). Админов подтверждает подписью владелец. Ключи владельца закреплены на устройствах участников |
| Запросы к серверу | Каждый запрос подписан ключом участника. Сервер проверяет подписи, права, версию ключа и не даёт откатить данные |
| Удаление участника | Сервер сразу перестаёт его пускать. Ключи его коллекций меняются, записи перешифровываются |
| Вступление | Только по ссылке-приглашению (7 дней, до 25 человек), каждую заявку админ принимает вручную. В ссылке есть код команды, поэтому подменить команду нельзя |
| Браузер | Строгий CSP, никакого HTML из данных, ссылки только http/https, буфер обмена очищается через 30 с, автоблокировка |

Сервер (и Cloudflare) видит только зашифрованные данные, имена участников и время изменений. Названия коллекций тоже зашифрованы.

**Что важно знать:**
- Ссылка команды (`#t=…`) не даёт доступа к паролям без мастер-пароля, но не публикуйте её.
- Удалённый участник мог запомнить пароли, которые уже видел. Смените важные пароли на самих сайтах.
- Кто может менять код сайта (репозиторий на GitHub) или сервера (аккаунт Cloudflare), тот может украсть пароли. Не давайте никому эти доступы.
- Мастер-пароль не восстанавливается. Периодически делайте экспорт.

## Запуск с нуля

Сейчас всё уже развёрнуто. Этот раздел нужен, только если ставить заново.

```sh
cd server
npm i
npx wrangler login
npx wrangler d1 create keybox                 # id базы вписать в wrangler.toml
npx wrangler d1 execute keybox --remote --file=schema.sql
npx wrangler deploy                           # адрес сервера вписать в js/config.js и в CSP (index.html)
openssl rand -hex 16 | npx wrangler secret put SETUP_CODE
```

Потом откройте `https://<сайт>/#setup=<SETUP_CODE>` и создайте команду. Код одноразовый: после создания команды он больше ничего не даёт.

## Разработка

```sh
node tests/core.test.mjs     # ядро: шифрование, роли, подмены, откаты
node tests/server.test.mjs   # сервер: права, подписи, вход, приглашения, удаление
node tests/serve.mjs         # http://localhost:8765/#demo - демо без сервера, данные в памяти
cd server && npx wrangler dev --local   # локальный сервер
```

Сборки нет, это чистый JS (ES-модули). Сервер использует те же модули `js/crypto.js` и `js/vault.js`, поэтому правила у клиента и сервера одинаковые. Единственная внешняя библиотека — `vendor/argon2.umd.min.js` (hash-wasm 4.12.0, MIT), подключена с SRI: `sha384-tP0Wy54CKmng7i9EoTlPySD0hBx6Octj0VS6MfwlnUu111MPa+JLm0CCbep6XJ1W`.

После изменения файлов приложения поднимите `CACHE` в `sw.js`, чтобы у пользователей обновился офлайн-кэш.
